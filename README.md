# Console Blind Typing
Simple console program for training blind typing.
## Features
- Colorful and Detailed results
- Up to 20 quotes and more if you want. Just add some urls in python script.
## Usage
Just execute it in your terminal and that's all, but you need to execute it with full path (I mean /Users/...) or it doesn't work. The program gets quotes for you to type from https://quotes.toscrape.com (you can change it in python script).
